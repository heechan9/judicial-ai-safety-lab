# Legal Change Pipeline — v2.0

v2.0 adds a research-safe legal-change layer.

1. MOLEG law-change history identifies changed statutes.
2. Article-level history narrows the affected provision.
3. Scenario/source mapping selects only impacted regression tests.
4. Constitutional Court result/status can force human review.
5. Proposed or pending material is never treated as effective law.
6. Evaluation evidence remains versioned separately from source evidence.

The Constitutional Court connector is capability/normalization oriented: it uses the fields publicly documented by the official Open Data portal without inventing undocumented query parameters.
