# Architecture v2.0
1. **TriGuard layer** — source/status guard, provenance and composite risk.
2. **Bunkering layer** — baseline-vs-AI, stress/evaluation contract and replay.
3. **AdversarialAI layer** — attack scenario, ASR and independent rerun readiness.
4. **FabGuard layer** — frozen baseline, drift, prioritized human review and evidence governance.
5. **Official legal-source layer** — MOLEG current-law/change-history contracts plus Constitutional Court public-data capability manifest.
6. **Legal Change Pipeline** — changed statute/article → impacted regression scenarios → constitutional-status guard → human review.

Court remains contract-only until an approved/public API endpoint is available. National Assembly remains a source slot for the next expansion.
